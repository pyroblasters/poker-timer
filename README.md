# Poker Timer

Minuteur de tournoi de poker (blindes, ante, plan de table, dealer/SB/BB, cashprize) en un seul fichier `index.html`, sans dépendance.

- Bouton "Écran projecteur" : ouvre une fenêtre d'affichage seul, pilotée depuis la fenêtre principale.
- Config sauvegardée dans le navigateur (localStorage).

Déploiement Netlify : aucun build, dossier de publication = racine.
